# 全市場寬度與看圖操作（2026-10-30）

市場寬度正式改由 `scripts/build_full_market_breadth.py` 讀取
`.cache/universe-full` 的完整普通股名單與日 K，涵蓋台股上市／上櫃、美股普通股／ADR，
包含小型股，不再只使用 `data/` 或 S&P 500。沿用原 MA20／MA60 計算：
收盤嚴格大於 SMA、當日有成交且歷史足夠才列入該均線分母；缺資料不視為跌破。
歷史仍以目前名單回推，含存活者偏差。市場休市／共同零量占位日沿用最近有效交易日。

全市場進場成功率原本已讀取相同完整名單，算法、門檻與月度歷史不變。

| 檢查 | 條件 |
| --- | --- |
| 完整名單最低數量 | TWSE 800、TPEx 500、US 3,000 |
| 名單最長年齡 | 14 個日曆日，不接受未來名單 |
| 當日有效日線覆蓋率 | 每個市場 ≥ 完整名單的 90% |
| 未通過 | 保留原寬度檔並使步驟失敗；不退回部分名單 |

上述門檻直接共用既有全市場進場成功率設定，沒有兩套不同的市場定義。
報表另帶出完整名單數、快取缺漏與未成交／停更數，收在「樣本與歷史說明」。
`universe-full.yml` 產生報表並由 generated owner `universe` 發布；daily owner 不再
產生／擁有 `breadth.json`，避免稍後的每日報告以 S&P 500 覆蓋。
舊 `build_breadth.py` CLI 保留供離線分析。兩個來源檔、日 K 快取、永久紀錄與
`kline-archive` 分支都只讀；本次不重新發布任何報表或行情。

全球標籤改為「日債」。美日債維持相同摘要順序；10Y−Fed 上／下限標題保持單行，
透過摘要欄寬比例與留白調整，不刪除利差口徑文字。
利率卡片的單欄 grid 也明確允許收縮，避免桌機縮到手機時被圖表上一個寬度撐開。

選股清單上方新增「連續看全部股票圖表」，沿用自選的日 K、成交量、六個月初始範圍、
縮放與捲動分批載入。只看當前條件、搜尋與排序的結果，返回清單保留條件。
優先使用個股已保存均線，再用該列／群組參數；不自動寫入任何參數。

個股頂部「K線／財務／價量／研究／建議均線／波動率」共用一組外框與按鈕樣式，
不把波動率推到右端。建議均線直接開浮動面板，價量只顯示分析；套用、取消套用、
固定參數流程與原分組優先規則不變。切換頁面仍保留原圖表實例。

研究的相對大盤頂部顯示全市場報表既有 `rsRank`（1–99），即 3 個月相對強弱
在同市場的百分位。資料日與原市場基準一併標示；下方報酬比較的期間／基準切換
不改寫此排名。缺少完整市場排名不以個股與指數兩條線推估；原報酬比較仍可使用。

題材圖使用既有可交易 ETF／成分股的真實 OHLCV 加入成交量，週／月 K 沿用
既有日 K 彙總。台股顯示張、美股顯示股；題材等權報酬指數沒有虛構 OHLC／成交量。
沒有成交量資料就顯示缺少，不補值。其他研究圖表預設維持原狀。

看圖、分頁載入、題材週成交量、單列操作、均線套用取消與資料缺漏測試。
