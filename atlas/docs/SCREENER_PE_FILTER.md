# 股票篩選：本益比

在「選股 → 篩選 → 基本面 → 本益比」設定。預設不限；提供 ≤10／15／20／30 倍快捷選項，以及可留白的自訂上下限（含邊界、最多兩位小數）。負數、上下限顛倒或無效輸入會阻止套用。可取消草稿、移除條件或重設，並與原有成交量、技術與財報成長條件同時使用。

數值沿用清單既有本益比：優先 TTM，TTM 缺值且非虧損時才用最近完整年度。台股優先採交易所 TTM，本功能不另抓即時行情。比較採既有估值計算的兩位小數；原清單仍依原格式顯示。虧損、缺少本益比或行情失敗的股票不通過數值條件，不受財報成長的「資料不足時排除」開關影響。

| 條件 | 網址 f 參數 |
| --- | --- |
| 10～20 倍 | `pe:10:20` |
| 至多 20 倍 | `pe::20` |
| 至少 10 倍 | `pe:10:` |
| 20 日均量至少 100,000 股，且 10～20 倍 | `vol:100000;pe:10:20` |

參數與原條件共用市場記憶、網址分享、自選策略與備份格式，不新增儲存 schema。舊網址與舊策略沒有 pe token 時行為不變。

開啟面板或套用本益比時，使用既有 ValuationProvider 的市場檔快取，對整個來源群組計算，不限於虛擬清單畫面上的股票。市場或群組切換後忽略過時回應。資料尚未取得時顯示載入狀態；整份資料檔不可用時顯示錯誤，不會把未篩選清單當成符合結果。自選清單遇到來源失敗會保留原有比較基準。

瀏覽器與離線自選收集器使用同一個計算入口。收集器僅新增讀取既有 `atlas/public/valuation/{tw,us}.json`（缺檔時沿用 `docs/atlas/valuation`）的適配，沒有修改 API、SQL、Supabase、workflow、產生程序或市場資料檔。

驗證由 `tests/screener-pe.test.ts` 與 `e2e-site/screener-pe.spec.ts` 涵蓋：邊界／無效參數、缺資料與虧損、條件組合、6,000 檔單次市場請求、畫面外股票、台美股、自選重載、取消／移除／重設、320／390px 無橫向溢位與延遲跨市場回應。結果與截圖見 PR；headless WebKit 不代表實體 Safari 裝置驗收。
