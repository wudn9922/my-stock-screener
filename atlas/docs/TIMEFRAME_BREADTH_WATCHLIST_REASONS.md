## 各週期的均線與畫線

在個股圖表選擇週期，打開「建議均線 → 自訂目前週期均線／畫線」，即可新增該週期的 SMA／EMA，以及固定／解除固定目前週期的設定。原本「指標」面板也提供相同控制。畫線仍由原圖表的繪圖工具新增、點線修改；新線預設 2px。

分 K、時 K、日 K、週 K、月 K 依目前資料來源支援的週期提供，不會用不存在的資料製造新週期。每檔股票、每個週期的物件與鎖定狀態獨立，其他週期的物件不會被覆寫。固定表示鎖定；解除後才可改參數／畫線或刪除。

使用既有圖表儲存：cloud／device 依目前授權保存，訪客僅本次記憶體，重新開啟即消失。不另存新組合，不修改儲存格式。日 K 的推薦與個股／分組監控參數仍維持原本行為；非日 K 畫面將這些工具收在「日 K 建議與監控參數」，避免誤把週線設定寫成日線監控。

## 市場寬度上下限

規則來自使用者提供的 `us-breadth-signals.zip`。`scripts/breadth_signals/` 共用附件的計算與交易規則，僅調整匯入路徑、輸出接線與失敗處理。美股沿用 NasdaqTrader 普通股及 ADR 的全市場名單；目前名單回推有存活者偏差，並非當年的完整上市名單。

有效日要求有收盤價且成交量大於零；各股票用自己的 K 線計算 SMA20／60，以已有對應 SMA 的有效股票為分母、收盤嚴格大於 SMA 為分子。依長歷史校準 P5、P10、P50、P90、P95，取代固定 20／80 界線。

| 區域 | 校準判定 |
| --- | --- |
| 極端超賣 | 比例 ≤ P5 |
| 超賣 | P5 < 比例 ≤ P10 |
| 中性 | P10 < 比例 < P90 |
| 超買／趨勢強 | P90 ≤ 比例 < P95 |
| 極端超買／趨勢強 | 比例 ≥ P95 |

低點訊號需同時滿足美股寬度 MA20 比例 ≤ P10，以及指數距近 60 個交易日最高收盤回檔到位：S&P 500／道瓊 5%、那斯達克／羅素 7%、費半 10%。沿用附件的首次成立、冷卻與持倉去重規則；次一交易日開盤進場，停利停損同幅，最多持有 60 個交易日。同日兩線皆觸及保守算停損，跳空沿用開盤成交規則。

顯示無訊號、等待回檔、新訊號、持有中、停利、停損、到期；全部無訊號時折成一行。走勢圖加入 MA20／60 的 P10／P90 虛線與可切換指數的訊號日期。超買只表示強勢，另列先跌機率及基準，不產生賣出提醒。台股保留全部寬度數字、走勢與分市場資訊，依附件研究明示訊號不適用。

資料與工作流程：

- `breadth-us-calibration.json`：長歷史分位數、各指數命中率與基準。
- `breadth-us-history.csv`：長歷史，daily 接上既有網站寬度；同日以網站為準。
- `breadth-signals.json`：前端唯一新增的唯讀訊號來源。
- 三檔都由既有 `universe` owner 發布到 generated；衍生 bootstrap 放在 `scripts/breadth_signals/bootstrap/`，不修改任何日 K、價格或財報。
- `breadth-calibration.yml` 每季／手動校準，與 universe 共用 concurrency，避免歷史互蓋。
- `universe-full.yml` 在原寬度成功產生後計算訊號，獨立 fail-soft。重疊差超過 3 個百分點或來源出錯時保留舊訊號，不阻擋原寬度發布。
- 無檔、格式錯誤、訊號日期與寬度不符時，前端保留寬度畫面，不套舊標籤；單一指數壞資料不拖垮其他指數。

持有天數以實際指數 K 線計算；附件對未來到期日使用工作日粗估，未扣未來美國國定假日，畫面會標為預估。歷史統計不保證未來結果，並非投資建議；本功能不發任何通知。

## 自選清單進出榜原因

原「新入選／出榜」改成可展開的股票列，顯示本次符合或未通過的條件與實際數值，並可開啟個股圖表。條件檢查直接使用原選股 evaluator，包含固定均線優先、成長條件、缺值保留、本益比與各邊界，不另寫另一套選股公式。台股平均量顯示張，美股顯示股。

比較仍是上次開啟與這次開啟的名單，不改每日 collector、保存基準或雲端格式。舊快照只有成員，沒有舊指標值，因此原因說明只聲稱本次條件證據，不聲稱「昨天剛穿越」等無資料的事件。股票消失於來源時明示無法判斷原始原因；整份來源或必要條件不可用時沿用原保護，保留上次名單。

原因僅存在本次 UI 記憶體，不新增私密持股資料、網址參數、analytics、log、推播或伺服器儲存。
