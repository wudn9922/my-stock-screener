## Drawing picker

The left rail and its reserved width are removed. A single 44×44px Drawing Tools button with an icon and “繪圖” in the chart toolbar opens an accessible categorized modal outside the plot. At widths up to 1099px, the duplicate delayed-snapshot CTA is hidden while the provider selector remains visible. Categories are Common, Lines, Channel, Shapes, Fibonacci and Measurements; together they expose all ten existing tools. Select/Pan, magnet, undo/redo, zoom, future area and reset view remain available through the picker and invoke existing actions.

Opening the modal cancels unfinished work but retains the chart and drawing controller. Choosing a tool follows the existing tool-selection path and closes the modal. The workspace behind the dialog is inert; focus handling, Escape, backdrop dismissal, safe areas and bounded scrolling are handled by the modal. The modal does not resize the chart. On mobile, category controls and the selected category's tool list occupy the sheet's left and right sides; category scrolling remains bounded in short landscape.

The right price axis uses Lightweight Charts 5.2.1's public `rightPriceScale.minimumWidth` with a 40px minimum. It is not a maximum: longer labels may take more space. Existing precision and native label sizing are kept, with no canvas clipping or abbreviated values.

## ATR width mode

New unspecialized drawings and newly added SMA/EMA instances default to `widthMode: 'atr'`; existing objects, custom styles, locks and saved defaults are not rewritten. The primary interpretation is a price-domain line thickness, not an ATR-distance band or a raw pixel multiplier.

ATR is Wilder's 14-bar calculation over the active symbol/timeframe OHLC. The first true range is high minus low; later ranges include the gap from the previous close. The seed is the first 14 true ranges and subsequent values use Wilder smoothing. The latest ATR is cached once per loaded data revision. The requested thickness is `ATR × 0.02` and is converted through public price-scale coordinates at the drawing's first-anchor price or the indicator's latest close.

When there is insufficient, invalid or flat OHLC history, the renderer uses the persisted `lineWidth` pixel fallback; no ATR or price bars are fabricated. Completed drawing strokes are bounded to 0.5–4 CSS pixels and at least one physical raster pixel. Native SMA/EMA series accept integer widths 1–4, so the calculated width is rounded to that range. Preview strokes remain 1px; selected strokes remain at least 2.5px; handles and hitboxes are unchanged. These limits mean the visible stroke is not exactly 0.02 ATR at every zoom level.

Settings offer 0.02 ATR or fixed 1–4 CSS-pixel widths. `widthMode: 'pixels' | 'atr'` is optional; absence preserves the existing fixed `lineWidth`. Volume and its average stay in pixel mode (the existing Volume default remains 2px) and cannot select ATR. Candles, grid, crosshair and control handles keep their prior styling. Existing style settings and locks still govern edits.

## Persistence and compatibility

IndexedDB and the settings export envelope move to version 4 to preserve the selected width mode. Migrations from v1/v2/v3 and imports of v1/v2/v3 JSON are validated and committed atomically. They preserve existing IDs, anchors, prices, widths, styles, locks, presets and preferences. Legacy widths are interpreted as pixels; old settings are not silently converted to ATR. A failed migration/import preserves existing data. Market snapshot schema remains version 3 and is unrelated.
