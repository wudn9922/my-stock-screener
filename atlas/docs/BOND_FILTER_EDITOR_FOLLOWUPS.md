# 債券排版、選股條件重置與畫線編輯

從 main `3334513d5` 開分支；此變更只供 PR 審查，不合併或部署。

## 債券頁

全球分頁改為「美債／指數／利差／原物料／匯率」。「利差」維持原日本
國債網址與頁面標題，按鈕提示其為日本國債。手機用五欄單列排版，
320／375／390px 都檢查不換行、不溢出及觸控高度。

日債加入與美債共用的三格摘要：10 年殖利率、10Y−BOJ 利差、日銀目標。
兩頁都依序顯示「摘要 → 合理區間 → 利差走勢」；原美債 ETF 與情境保留。
日銀資料為單一政策目標，因此目標區間格只顯示該數值，不虛構上下限，
並在提示及折疊來源中說明。

摘要的月變動沿用相同格式；日債以報告日期往前一個月的真實觀測計算。
利差變動要求當時 10Y 與政策目標日期相同；缺少歷史時顯示未知值。
官方檔案缺失時仍明示附件基準快照，不把附件當即時行情。

## 選股條件

暫時條件只屬於目前網址，不再自動讀寫各市場的舊條件偏好：

- 切換群組／市場時清空條件，並關閉舊的條件草稿。
- 從主導覽重新進入選股，或開啟沒有 `f` 的選股網址時，從無條件開始。
- 明確帶 `f` 的分享網址、瀏覽器歷史網址或重新整理同一網址仍保留條件。
- 已儲存自選清單的策略、重新評估及持久保存不變。

既有偏好資料及匯入／匯出輔助函式保留，不刪除帳號設定。搜尋文字與排序
不是本次清除的篩選條件；在同一頁調整條件也不會被背景計時器清掉。

## 畫線編輯

原生 dialog 會聚焦第一個可操作欄位，iOS 可能因此直接打開第一個顏色
輸入欄。個股快速編輯器改以「取消」作為第一個聚焦目標；顏色輸入維持
瀏覽器原生控制，只有使用者操作顏色欄時才進入選色流程。

DrawingSettings 新增可選的成功回呼。快速編輯在驗證及記憶體提交成功後
自動關閉，不再多按「完成」；錯誤仍留在編輯器，舊的非快速編輯面板不變。
沿用既有儲存佇列與失敗提示，不改畫線、價格／時間座標、手勢或歷史模型。
沒有修改共用帳號 dialog、登入／帳號程式或 Supabase 函式。
