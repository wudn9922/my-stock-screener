# ADR-029：市場休市證據與唯讀 K 線投影

## 2026-11-07 官方空行情佐證與指定資料修補

四個待查日已由 TWSE／TPEx 指定日期雙來源空行情確認：2022-02-04、2023-01-18、2024-10-31、2026-07-10。共享 seed 的 `official-no-quotes` 需精確官方 URL、日期、零列與回應 SHA；Python／Zod 都驗證。舊 missingSessions 不能推翻此證據，股票成交或官方交易證據仍能否決。未知量不當零量；10/23 可在刪列後零觀測時延用已核對隊列證據。完整投影 cache 升 v6，raw 年檔不變。

本次使用者另明確授權兩個缺日補檔、10/23 指定零量平盤刪除與完整還原工具。它們是預設 dry-run 的維護操作，先驗證、備份並核對 hash，再沿原年檔／index／manifest 寫入與驗證；不是日常 producer 的自動修復。真正永久寫入由維護者審查後自行 dispatch。對所有封存內容逐位元組回到指定刪除前 Git parent 的還原，新增可獨立驗證的窄歷史例外；普通歷史保護不變。詳見 [操作與證據](../../../docs/ARCHIVE_OFFICIAL_REPAIR.md)。

## 2026-11-07 修訂（取代原指數缺列OR規則）

XTAI確認2021-04-06是交易日，TPEx ^TWOII也有207.79／209.81／207.79／209.70的OHLC；原本因^TWII與普通股皆缺資料而判休市，是錯誤推論，現已撤銷。

共用核心先查XTAI／XNYS。正量≥5%或至少50檔仍優先保留；日曆非交易日可判休市；日曆交易日須同時有「主要指數缺列＋≥95%有效普通股零量平盤」才能證明臨時休市，且有已驗證官方當日資料時不套此推論。10/23具完整證據、10/26為日曆休市，結果不變。其餘交易日缺資料改列 `missing-session-data`，保留現存列；日曆不可用不猜新的工作日休市。

官方TPEx與主要指數均驗per-symbol index／SHA-256／bytes／rows／日期。原普通股分母、未知量、樣本數及近期覆蓋要求不變。新metadata帶 `calendar`／`calendarSession`，`missingSessions`撤銷舊休市；frame lineage只保留少量臨時休市證據，避免下游切片因已移除假列而失去10/23證據。

新增2021起已收盤session的唯讀缺漏掃描：主要指數缺列或>50%可觀察普通股缺列即列疑點／受影響檔數，`coveragePosition`區分既有覆蓋內缺口與最新收盤待封存。firstDate只作可觀察起點，不當IPO日期；未推定下市日，現行目錄有存活者偏差。無官方交易佐證的全空日期可能是臨時休市或日曆誤差，保持待查，不自動補檔／排除。

前端嚴格Zod要求日曆與臨時休市證據；新版種子移除2021-04-06休市，`missingSessions`優先保留。raw年檔不變，完整投影cache升v5，防止沿用舊的隱藏結果。新增 `scan_market_data_gaps.py` 獨立入口，與 `scan_market_closures.py --missing-out` 共用一次讀取核心；輸出不能在archive內。詳見 [最新掃描與限制](../../../docs/MARKET_CLOSURES.md)。

永久價格／財報／archive只讀，原追加、衝突、拆股與稽核不變；均線評分、道氏、研究公式／門檻及前瞻紀錄不變。沒有改登入、Supabase、GCP或新增輪詢。

<summary>原決策歷史（以下休市判定由上方修訂取代）</summary>

日期：2026-11-06。永久封存只讀；既有日曆、統計定義、風險門檻與即時訂閱不變。

問題是資料源會在全市場休市日送出零量平盤列。2026-10-23 的台股封存有 2,214 筆這類列，造成圖表假十字線，也讓警示計算的交易日窗口包含沒有交易的一天。單一股票零量平盤可能只是停牌，不能據此刪除它的有效觀測。

`scripts/market_sessions.py` 共用同一判定（修正原prompt的OR規則）：有效普通股正量占比≥5%或至少50檔時一律保留，指數缺列只記為 `primary-index-gap-with-trading`。未達成交證據時，成功取得且驗證完整的主要指數（台股 ^TWII、美股 ^GSPC），在其首末已收盤日期之間缺少某日；或有效普通股樣本至少 95% 為已知零量且 O=H=L=C。量未知不當成零，指數／ETF 不增加普通股樣本。保留原有近期覆蓋檢查；即時快照以完整有效名單當分母，不因只回來少數股票就判定休市。封存掃描／stage 沿用至少 50 檔的檢查，既有分析 API 保持至少 2 檔。週末仍排除。

指數抓取失敗、SHA 不符或超出其首末日期都表示未知，不能當作休市；不推測尚未收錄的今天。這是對來源缺漏的保護，不是另外一套交易日曆。XTAI/XNYS 預定日曆仍用於已收盤邊界，資料證據補足臨時休市。指數缺列但股票正常成交的日期不排除；沒有任何股票觀測的缺列日期仍判休市。報告公開正量數、占比與覆蓋範圍供查核。

掃描與每日快照產生 `market-closures.json`，包括原因碼、普通股觀測／零量／未知量數、覆蓋參考與來源時間。universe owner 透過現有 generated 發布；不是永久價格檔，也不發通知。掃描器只讀 archive，報告不能輸出到 archive 內；可重跑而不改一個永久位元組。較新的已確認休市證據不因封存尚未追上而被抹除。

每日 cache 寫入、bootstrap、ETF／指數補充與 stage 共用排除日期。一般追加不攜帶休市日；既有封存日期不刪除，真正拆股的 transport 也保留原有休市列原值，避免藉修正移除永久日期。分析投影先排除休市日再建交易日序列；完整樣本投影附 lineage，之後按產業或月份裁切時不再把少數停牌股票誤判成市場休市。突破的既有週末排除計數保留。

前端在原 `KlineArchive` 資料層驗 SHA、讀 raw 年檔後，才以市場日期過濾；日 K、週月彙總與 live 合併使用同一結果。既有 year／完整行情快取換版，防止舊的「單股零量即休市」投影繼續沿用。動態報告每 UTC 日／頁面最多一個有逾時上限的請求，不新增輪詢；缺檔／格式錯誤保留上一份有效證據，首次失敗則使用唯讀掃描產生的極小歷史種子。種子只包含實際影響封存列的已查核日期，與掃描 commit 一起交付，不硬編造節假日。

本 PR 不修改永久 K 線、均線評分、道氏狀態機、研究門檻、通知、登入、Supabase、GCP 或封存發布器。詳見 [掃描與重現說明](../../../docs/MARKET_CLOSURES.md)。
