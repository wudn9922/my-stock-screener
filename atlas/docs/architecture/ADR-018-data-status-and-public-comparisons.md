# ADR-018 — 唯讀資料狀態與公開比較快照

狀態：依本次使用者要求新增；保留既有頁面、資料、帳號、外框與服務程式行為。

資料新鮮度由 Python 與 exchange_calendars 集中判定，所有來源政策集中在 `SOURCES`。前端只讀小型 `data-status.json`；來源失敗逐筆隔離，不在瀏覽器下載 universe 推論日期。archive 只讀 manifest，工作流程只以 owner delta 非 force 發布新 generated 衍生檔，不修改永久價格或財報。

任意選股條件要比較兩個交易日，必須保存當時的公開輸入。新增首次寫入後不覆寫的市場日快照與日期索引（每個市場只保留最近 10 個資料日，屬衍生輸出而非永久紀錄），保留捕捉時間、原始行情及財務輸入；不以目前財報回填歷史。缺觀測不推定離開，條件輸入不完整就停止比較，固定均線以既有設定對齊歷史日，不改儲存模型。

相對大盤沿用 provider 與現有 TimeChart，資料按各市場交易日交集對齊；不修改主 K 線引擎或 canonical 畫線座標。產業彙整在後端讀取 rolling cache，前後期量能採完整共同樣本；前端只讀小檔，不逐檔請求全市場 K 線。

完整來源門檻、入口、限制及驗證見 [資料狀態與比較功能](../DATA_STATUS_AND_COMPARISONS.md)。
