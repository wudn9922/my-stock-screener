# 多頭末期警示

市場頁台灣／美國在全市場進場成功率上方顯示三項獨立風險警示。它們不改均線評分或道氏趨勢狀態，也不預測修正時間。美股價量燈號不計分，顯示「不適用（無歷史驗證）」。資料不足與未亮燈分開顯示。

指數價量預設 60 日，上漲日／下跌日使用不同分母；5、10 日線每週取最後可用值。圖中另保留 60 日平均與過去中位數。第二圖為領頭羊與全市場同口徑成功率，第三圖為 21 日累計的每千檔突破數。三圖可用原生滑動、捏合／滾輪縮放；灰底為百分比 zigzag 的事後修正段，不是當時可得訊號。

全部門檻與研究原文位於卡片收合的「計算說明」，讀自經 Zod 驗證的 `market-warnings.json`。無法讀取或格式不符時沒有數值，提供原因與重試；不沿用另一份舊數字。

## 計算與發布

```bash
python scripts/build_market_warnings.py --cache-dir .cache/universe-full
```

這是正式排程的產生器說明；本 PR 不手動觸發正式 workflow。維護者合併後由原 universe-full 排程，在完整市場突破統計之後執行。步驟與其額外依賴安裝均 continue-on-error，覆蓋／名單／指數失敗保留舊 JSON，不擋其他輸出。

個股只讀原完整名單與日 K cache；指數由既有 Yahoo 日線來源取得七年資料供三年圖表與 warmup。SOX 使用 SOXX 同日期量。XTAI／XNYS 排除尚未收盤日，市場共同零量占位日沿用既有排除規則。股票與指數 OHLC、快取、永久行情、財報與 kline-archive 都不寫入。

- `market_warnings_params.json` 定義獨立警示窗口、分位、流動性與風險門檻；A2 的 ATR／收盤確認／五日守住常數直接取自既有共享核心，避免說明和實際計算不同。
- `market-warnings.json` 是 universe owner 的 generated 衍生輸出，兩市場各有 asOf，圖表保留三年日期，無法計算的早期日保留 null。
- `market-warnings-log.csv` 是 main 的 durable append-only 紀錄。鍵為 market＋asOf，保存計算時間、門檻 SHA-256、完整性、燈號與數值。重新執行相同資料日不更改第一次紀錄，並行同鍵保留遠端先發布者，其他日期做聯集。
- `generated_branch.py` 與 legacy 發布前都驗證舊 CSV 是新內容前綴，拒絕刪除／截短／改寫。永久日誌不進會 squash 的 generated。

## 波段口徑

`first-higher-close-v1` 使用原 `atr-reversal-v2`，僅改計數：每個 pivot 第一次、且不低於上一已確認高點、且突破日收盤達關鍵點＋0.1 ATR(14) 的事件進入觀察。缺少前一高點不猜測。完整五個後續市場交易日最低價均大於關鍵點的 95% 才成功；待觀察與缺日不算失敗。

重試／較低高點／收盤沒站上另列，定義與分母見 JSON params。新波段固定顯示五日守住；箱型與20EMA原四組判定不變。月度結果同引擎重算，既有快照 bytes 不變。舊快照標示舊口徑，混合口徑的月份不畫比較柱。

## 已知限制與待審口徑

1. 研究原文由使用者提供；本次試算不是重新驗證 2005–2026 的 p 值。當前名單有存活者偏差。
2. 原 cache 最多320根，首次產生不足400個有效突破家數，第三燈會是資料不足。後續保存已算過的日期序列累積門檻；不把短歷史當三年分布。三年日期區間不代表三年每個值皆可用。
3. 21日次數的分母依任務文字採同期有效股票聯集，未除以21；與研究「每千檔每日5.6／2.8」不是相同單位。領頭羊依任務 t 的記法，採每個觀察日 t−1 的名單篩選該窗口的成熟突破；不是每個突破日各自的名單。這兩個解讀在 PR 明列供審查，未暗中調參以貼近研究數字。
4. 停牌、來源缺漏、未知前高與冷啟動會減少樣本；五日平滑需五個各自至少15次的有效日值。價格異常會重新開始波段，126日端點報酬不跨已知大幅跳價。
5. 灰底含未確認末段，會隨後續價格變動。圖表的歷史回算可更新，前瞻 CSV 首次紀錄永不重算。
6. 本機試算使用先前由唯讀封存 commit `4c934296ac3bb1003d0d4a7f106d21a099cddb87` 種子重建、每檔保留320根的 universe-full 格式快取；名單日2026-10-25。不是本次重新下載的最新 Actions cache，資料日至台股2026-10-22、美股2026-10-23。PR 預覽明列原日期，不冒充當天即時資料或正式站已更新。
