# 圖表價位與自選清單操作修正

此變更從 main `3cece7a70` 開始，保留已合併的持股、MEXC、突破／跌破訊號與資料健康功能。
不修改登入／帳號程式、Supabase 函式或 SQL、網站頂端／底部導覽，以及永久行情資料。
不發送通知、不合併或部署。

## 1. 每檔股票用自己的價格範圍

手動拖曳 Lightweight Charts 價格軸會關閉該軸的 autoscale。Atlas 重用同一個圖表／
價格序列，換股票後雖已換成新資料，手動價格範圍仍留在上一檔。

瀏覽器重現使用合成的約 20 元與 2,000 元股票：先拖第一檔的價格軸，再搜尋第二檔。
舊程式的 OHLC 已顯示 2,000 元，但主圖上半部的紅綠 K 線像素數是 0。
修正後同一個實際瀏覽器渲染檢查能看到第二檔 K 線，桌機／手機／WebKit 都有覆蓋。

`ChartEngine.load` 在 symbol 或 timeframe 改變時，透過既有公開 API
`candles.priceScale().applyOptions({ autoScale: true })` 重新啟用自動價格範圍。
同股票同週期重新載入資料時保留原本的手動縮放；「重設視圖」也重新開啟自動價格範圍。
各股票原有的時間軸視窗、繪圖時間／價格座標、指標與鎖定資料不會被清除或改寫。
沒有升級 5.2.1、重建圖表或使用私有 API。

## 2. 自選分組放在行情清單上方

「我的清單」進入預設清單（沿用文件中的第一份清單）；選項正下方提供「自選清單」
下拉選擇，直接切換其他分組。原本管理區最下方的重複分組按鈕移除。
使用下拉選擇仍走同一個清單 ID／路由、評估與雲端同步流程，不重新建立或累加清單。
原有重新開啟比較、監控開關、改名、匯入／匯出與刪除功能保留。

移除的「最近搜尋」只限自選行情來源；全站搜尋本身的歷史與保存規則不變，不刪使用者資料。

## 3. 連續看所有股票圖表

「我的清單」與「LINE 熱門」在股票列表上方都提供「連續看全部股票圖表」。
切換後依原清單順序顯示日 K、成交量、最後價格、前一交易日漲跌與日 K 日期；
可返回原本的行情列表，也可從任何卡片開啟既有個股工作台。

- 每批 20 檔，接近末端時自動載入下一批，保留按鈕作為鍵盤／無 observer 的替代方式。
- 圖表只在畫面附近掛載，離開時釋放 canvas；固定高度避免清單跳動。
- 垂直觸控與滑鼠滾輪用來捲頁；縮放使用按鈕或雙指手勢。
- 使用既有 MiniChart／行情 provider，不加預設股價均線、不修改個股指標設定。
- 無行情明示「暫無圖表資料」，不造資料；日期以真正最後一根日 K 為準。
- 沒有新增持股、帳戶、監控或價格寫入；顯示分組只用現有授權資料。

## 4. 財務與其他個股選項一致

「K線／財務／價量／研究」的緊湊尺寸由 StockTabs 的共用樣式管理，圖表與財務都使用
同一個 controls 容器。財務頁先顯示股票身分，再顯示四個選項，手機也保留公司名稱。
年度／季度與圖表／表格維持原操作，次要查詢放右上方並保持收合。

原有手機頁首 112px 高度限制與「頁首可隨財報捲走」檢查保留，沒有放寬測試。
資訊、搜尋、查詢連結、品質說明、財報數值、來源說明與圖表縮放均保留。

## 驗證與限制

新增 `e2e-site/chart-watchlist-followups.spec.ts` 驗證真實 canvas 渲染、分組位置／預設、
60 檔連續看圖／自動分批／釋放 canvas，以及財務／其他個股頁的四個選項尺寸一致。
既有分組測試改驗證下拉選項數與選擇結果，既有功能斷言保留。
另跑日／週／月指標與繪圖的重載、匯出隔離回歸。

使用合成行情與假服務；沒有讀取正式個人資料、真實券商 API 或更動永久 K 線。
實際測試數與 CI 結果記錄在 PR。Headless WebKit 不代表實體 iPhone 效能或手感驗收。
