## 公式及附件

`atlas/data/yield-band-params.json` 保留使用者 2026-10-29 的參數快照，
`tests/fixtures/yield-band/reference.js` 保留其 JS 計算式作為單元測試對照。
Python 實作不需要 numpy；沒有增加套件。原始附件中的歷史報價不會被當作
今天的報價寫入報告。

| 方法 | 中心 | 標準差 | 上下緣 |
| --- | --- | --- | --- |
| 回歸 | a + b × 政策利率 | OLS 殘差，自由度 n−2 | 中心 ± 1.2816 × 標準差 |
| 利差 | 政策利率 + 歷史平均利差 | 利差樣本標準差，自由度 n−1 | 中心 ± 1.2816 × 標準差 |

狀態界線與附件相同：z = ±1.2816、±0.5。80% 是歷史模型參考帶，
不是未來價格或報酬的保證。模型樣本數、起迄年月、R²、參數更新日及
行情日可查閱。美國即時比較使用 Fed 上限，日本使用 BOJ 目標。

## 讀取與失敗顯示

前端只抓同源兩個小 JSON，不從瀏覽器打 FRED、MOF、BOJ 或傳 API key。
快取沿用現有 30 分鐘 loader，請求有 15 秒中止與清理；國別模型各自驗證。
報告缺少時顯示附件 **2026-10-29 基準快照，並非即時行情**，不生成歷史曲線。
已載入但過期／部分來源缺失的日本報告顯示實際資料日；舊模型不重蓋更新日。
美國舊報告若無政策或殖利率，合理區間呈現不足訊息，既有內容照常可用。

## 發布方式

沒有新的服務、SQL 或 Edge Function 部署。維護者合併並依原流程發布網站後：

1. 既有 `refresh-us-rates.yml` 會因收集器路徑變動自動執行；也可手動跑。
   `schedule.yml` 每次原每日工作後也會產生新報告。
2. 沿用既有 FRED_API_KEY（可選）；兩個來源加到 daily／rates 的 generated
   owner，沿用 generated_branch 的樂觀併發保護及失敗重試。原報告 owner 不變。
3. 新報告保持 Git ignore，舊相容模式只明確 force-add 這兩個可重建報告。
   不寫永久價格、財務、K 線或 kline-archive，也不發送任何通知。
4. 收集失敗不阻斷原美債報告發布；初次沒有報告時，網站提供明確基準／重試。
