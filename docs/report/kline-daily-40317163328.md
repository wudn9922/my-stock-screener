## Root cause and replay

The unmodified implementation was stopped after 65 seconds on the real payload:
at 4,500 conflicts / 60.497 seconds it had made **4,500 full JSON writes**,
rewritten **3,455,700,140 logical bytes**, and grown the file to 1,538,333 bytes.
It also rereads/parses the growing state before every write. The final identical
snapshot then repeats those lookups because any conflict prevented the previous
daily-operation checkpoint from being retained. This confirms the quadratic
conflict path; archive verification is not the bottleneck in that failed job.

The fixed replay uses a fresh shallow checkout and a **local bare origin**:
no production push, workflow dispatch, merge or deployment. Final-code measurement
(alongside other local test workers):

| Stage/result | Fixed replay |
| --- | ---: |
| apply_operations | 29.102 seconds |
| Full verification | 47.180 seconds |
| Apply + verify + local commit/push | 78.944 seconds |
| Rows added / corrected / conflicts | 3,526 / **0** / 50,286 |
| Conflict summaries | 6,710 |
| Conflict JSON | 5,614,993 bytes |
| Duplicate final operations skipped | 6,721 |
| Verified CSVs / rows | 21,155 / 3,484,356 |
| Identical second apply / byte changes | 18.506 seconds / **none** |

All original rows remain authoritative. Verification still rejects deleted
files/dates, unlogged historical modifications, altered prior audit records and
inexact manifests. Conflict counts now describe distinct observed dates per
symbol/reason, with a date bitmap (at most 366 bits/year), range and three bounded
samples. A second identical import leaves state and CSV bytes unchanged.

## Source policy proposal — NOT implemented by this PR

**Keep all current disagreements as conflicts for now.** The change batches and
compacts reporting; it does not change equality, add a tolerance, prefer an
incoming source, or authorize historical overwrites. The data supports a future
documented precedence rule more strongly than a broad tolerance:

* For TW, prefer a finalized TWSE/TPEx session bar when its session, share-volume
  scope and split-adjustment basis have been explicitly aligned. Use Yahoo for
  gaps. Record the source with the bar, and require an explicit audited correction
  to replace an already archived Yahoo row. Official closes and split-adjusted
  historical OHLC cannot be mixed just because both providers use the same date.
* For US, retain Yahoo chart as the historical reference, treating quote-batch
  daily observations as provisional until chart reconciliation. Split-size
  discrepancies need the existing proven-adjustment workflow or investigation.
* Only introduce a narrow numerical tolerance after identifying a specific
  representation error and documenting its bounds. Four-decimal canonical
  comparison already removes smaller price representation noise. It cannot
  explain the 8,377 TW volume cells differing by more than 1%.

In plain terms: keeping conflicts preserves evidence but leaves some normal
provider differences visible. Ignoring differences is cheap but can hide bad
volume or split bases. Source precedence gives consistent data, but needs source
metadata and an explicit migration so historical results do not change without
an audit. The artifact itself does not include per-row source provenance, so it
does not establish the precise exchange/quote cause of every individual mismatch.

## Reproduce without publishing production data

Download artifact 12647897306 through the GitHub Actions artifact API, verify the
ZIP hash above and extract to `/tmp/payload`. Clone the archive with `--depth 1`
and confirm the exact commit before running the read-only comparison:

```sh
python scripts/analyze_kline_archive_payload.py \
  --archive-dir /tmp/archive --payload-dir /tmp/payload --output /tmp/comparison.json
python -u scripts/kline_archive.py apply \
  --archive-dir /tmp/archive --payload-dir /tmp/payload
python -u scripts/kline_archive.py verify --archive-dir /tmp/archive --base HEAD
```

Do not run the publisher against the production origin for a reproduction. To
test commit/push, create a local bare copy and change **only the disposable
checkout's origin** to that local path first.

unchanged CSV digests and archive provenance. Default tests cover the actual
