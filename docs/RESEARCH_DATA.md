# Public research datasets — research-v1

This extension retains Python → versioned static reports → React/TypeScript on the existing `/my-stock-screener/atlas/` Pages site. No database migrations, new credentials, paid APIs, notification defaults, order execution, chart overlays, or user-data migrations are introduced. The original price cache, universe, chart engine, authentication and LINE jobs remain authoritative.

## Contracts and provenance

`docs/report/research/` has five module indexes (`institutions.json`, `volume.json`, `alerts.json`, `sec-radar.json`, `world-assets.json`) and **seven compact market files**: `volume/{TW,US}.json`, `institutions/{TW,TWO}.json`, `turnover/{TW,TWO}.json`, `sec/US.json`. All 10,384 original stock/date records were compared with the preceding commit and retained, excluding run clocks. Official turnover still retains up to 120 published sessions per market. No historical observation was discarded for compaction.

Run clocks (`generatedAt`, `fetchedAt`, `checkedAt`) occur only in module indexes, including source/event receipts. Market records keep source/sourceUrl, observation `asOf`, nullable official `publishedAt`, status, missingReason and methodVersion. Timestamp-only changes are compared recursively and do not rewrite even the indexes. Thus the index clock is the last **published material change**, not proof that a no-change collector ran; Actions logs show each execution. Source publication and SEC acceptance dates remain significant data. An unknown acquisition time stays null. Retained data never gets relabelled with today's observation date.

Storage format `research-market-v1` uses a deterministic shared field table. Objects are `[shapeId, ...fieldValues]`; lists are `[null, ...elements]`; primitives/null are unchanged. `shapeId` is the first 12 hex characters of SHA-256 of the sorted JSON field-name array, with collision detection. A market file is a valid JSON array with one encoded record per line, sorted by symbol (or date for turnover). Index `storage.markets[market]` holds `path`, `shapes`, `records: {symbol: [UTF8ByteOffset, byteLength, ordinal]}`, `bytes`, and `sha256`. Turnover's manifest is `institutions.json.turnoverStorage`. Stable shape hashes prevent unrelated records changing when a new shape appears. No gzip archives are committed: normal Git delta packing can reuse unchanged lines/history.

Stock panels first fetch the module index, then HTTP `Range` for only that record. GitHub Pages **206** support was verified on the existing public universe JSON. Actual local Pages desktop/iPhone WebKit tests retrieve volume records of about 5 KB and institutional histories of 36–41 KB. A server returning **200** is supported by selecting the indexed ordinal from its complete market array; that fallback downloads a market file. Symbol identity and Zod contracts are validated, aborted stock requests cannot replace a different stock, and an index/data deployment race retries once. Files are atomic; artifact checksums are verified before publication. Expected source failures retain data with stale/unavailable status; programming errors prevent that module's artifact from being published.

Histories remain bounded to 120 institutional sessions / 53 TDCC observations / 21 inspectable volume features / 400 calendar days of SEC and notices (official dispositions stay archived because an advertised end does not establish release). Institutional estimates retain their positive-day price inputs. The full-market Actions cache and `data/*.csv` remain the canonical daily price system; no second quote service was added. Missing data remains null and never an invented zero. Percentages use 0–100, changes in ownership use percentage points, and source price/volume adjustment limitations remain explicit.

Migration/reproduction: `python scripts/research_store.py --root <report-dir>` reads legacy per-stock/date files, writes the market format, reloads and checks semantic equality, then removes the old files. `MarketStore` is shared by collectors and the coverage audit. The real US ticker **TW** is distinguished from the Taiwan market file by the legacy record contents. Source cache eviction rehydrates from market snapshots; no absent date is cached as zero.

## Calculations

* RVOL20 = current positive-volume completed daily bar / mean volume of the **previous** 20 positive-volume valid daily bars. Today is excluded. Fewer than 20 valid predecessors → null. Ordinary 5/20/60-day volume means and 5/20-day amount means **include** the latest completed session; every mean exposes its observation count.
* In each 5/10/20-session window, each directional denominator includes only valid daily returns with a known causal RVOL baseline. Up-shrink = up days with RVOL < shrink threshold / valid up days ×100; down-expand = down days with RVOL > expand threshold / valid down days ×100. Up-expand and down-shrink stay separate. Equality is neither shrink nor expand. Defaults are 1/1; abnormal-volume defaults independently use ≥2 / ≤0.5. No directional days → N/A. Small samples (<80% or fewer than 5 observations) are labelled low confidence. No composite score.
* Missing/zero-volume rows break directional streaks and are not silently treated as trading returns. Known corporate actions and >40% unconfirmed jumps conservatively invalidate a comparison and restart volume warmup. This does not claim all dividends/splits can be identified from OHLC alone; the price/volume adjustment limitation is displayed. Market session dates are taken from existing daily CSVs and current-day incomplete bars are excluded using Taipei/New York clocks.
* ADV = mean daily turnover in local currency. Official same-day TWSE/TPEx amount is preferred; otherwise close × canonical shares is an explicit **turnover proxy**. `officialObservations` exposes the exact count of official inputs. Canonical daily volume and official market shares can differ: the former stays authoritative for chart-aligned volume signals; the latter is separately shown and used for institutional net/market-volume ratios. Never divide official amount by a different provider’s volume to estimate market VWAP. Amihud20 = mean(abs(daily fractional return)/daily local-currency turnover) ×1,000,000, with daily frequency and per-million-local-currency units shown. High-low range = (high−low)/previous close ×100; it is not bid-ask spread. No cross-currency ranking is performed.
* Institutions 1/5/10/20/60 = sum of actually available official net shares over that many published market sessions. Missing rows reduce the observation count; incomplete windows never claim complete coverage. Consecutive net-buy/sell runs break at missing market-session rows. Taiwan lots = shares/1,000; stored data stays in shares.
* Large holders >400 lots = grades 12–15 shares / grade 17 inventory ×100; >1,000 lots = grade 15 shares / grade 17 inventory ×100. Counts sum the corresponding holder grades. Differences are percentage points. Week comparisons seek an actual calendar-week baseline within 3 days, never use a different missing week's array index. 52-week changes require 53 retained weekly observations. These are depository-account distributions, not precise ultimate-beneficiary consolidation or institutional transactions.
* Estimated positive-net-buy-day reference = Σ(market daily average × max(institution net shares,0)) / Σmax(net shares,0). Zero denominator → N/A. Market VWAP = official amount/shares when available; TWSE/TPEx dated market reports supply the preferred amount and shares; missing official inputs fall back to the explicitly labelled **closing-price proxy**. A >0.5% disagreement between official native close and the canonical close excludes the estimate day to avoid mixing split-adjustment bases; suspected large price-basis breaks also exclude earlier incompatible prices. The current distance is N/A when its price basis is uncertain. Per-role 5/20/60-session outputs include close range, market-average/proxy range, matched days, positive days, coverage, current cached close/date and distance `(cached close/reference−1)×100`. This cannot identify actual holdings, remaining inventory, account owners, trade-level fills or a defended price. No per-stock official institutional monetary-fill data is claimed; aggregate market institution turnover cannot establish a stock's institutional cost.
* Asset changes = `(latest/baseline−1)×100`, baseline is latest actual observation at/before the calendar target. Maximum baseline lag: 7 days daily, 45 days monthly; no interpolation. Monthly 1d/1w is N/A. YTD uses the current year's previous-year-end baseline and is N/A when the latest observation is from an older year; month/year targets use calendar shifts, not fixed 30/365-day approximations. Monthly dates represent the observation month (first day), not publication on that day. Spot history can include negative observations without inventing a positive price.

`Research public data` now has two scheduled runs per trading weekday, **at most one commit per run**:

| Run (UTC) | Market timing | Modules |
|---|---|---|
| `23 11 * * 1-5` | 19:23 Asia/Taipei, after official daily reports | Institutional + official turnover, Taiwan volume, notices/dispositions |
| `23 5 * * 2-6` | 00:23 EST / 01:23 EDT (prior US trading session); UTC Saturday includes US Friday | US volume, SEC, world assets |

The Taiwan run follows the daily screener at 08:47 UTC and its dependent full-market cache. The US run follows the 03:17 UTC cache recovery (60-minute budget), allowing the previous US close and final SEC daily index to be available. Delayed/failed upstream jobs still retain and show actual dates. Manual/code-change runs collect all modules, still with one publisher. Jobs retain 18-minute timeouts and 600-second remote collection budgets. Taiwan volume receives this run's validated institutional artifact so its official turnover does not lag a run. A failed module has no output artifact; other successful artifacts can still publish. `fail-fast:false` keeps unrelated work running. When data is unchanged, the publisher creates **no commit and no Pages deployment**. Ten scheduled commits/week is the upper bound, compared with roughly 100 previously; holidays/source lags normally reduce it.

The workflow defaults to `contents: read`, collector checkouts disable credential persistence, and only the final `publish` job has `contents: write`. Collectors upload allowlisted/checksummed JSON artifacts. The publisher validates all artifacts before overlaying files, refuses a changed research implementation, and performs a single non-force push with race retries. Publication is restricted to `refs/heads/main`; running a branch preview cannot publish unmerged code/data. No collection or SEC document content is executed in the write job. Existing reporting, LINE, Supabase and TDCC schedules are unchanged.
